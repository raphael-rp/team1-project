## Setup Instructions

### Prerequisites
- Node.js
- npm
- Git
- MongoDB connection string

### Installation

1. Clone the repository.

2. Install dependencies:
   npm install

3. Create a `.env` file in the project root.

4. Copy the variables from `.env.example` into `.env`:
   MONGODB_URI=your_mongodb_connection_string
   PORT=3000
   SESSION_SECRET=your_session_secret

5. Replace `your_mongodb_connection_string` with the actual MongoDB connection string.

6. Start the application:
   npm start

7. Open:
   http://localhost:3000
